# Outputs

| Directory | Contents | How it is produced / used |
|---|---|---|
| `main/` | `review_outcomes.json`, `credit_report.json`, `run_manifest.json` for the 2,000-row outcome snapshot; 799 valid model results, one invalid response, and 1,200 provider failures | `./scripts/run`; the manifest records model/provider, price assumptions, usage, status counts, and output hashes |
| `evaluation/` | Synthetic-truth quality and seeded sensitivity reports | `PYTHONPATH=src uv run --locked python -m fundo_reviewer.evaluation --review-dir reports/main --output-dir reports/evaluation`; whole-cohort metrics include fallback rows, so consult `SOLUTION.md` for valid-model-only denominators |
| `new_input/` | Three-row example outputs for the offline quick start | Replayed without an API key from `cache/new_input.jsonl`; automated checks compare all three files byte-for-byte |
| `experiments/` | Historical prompt/provider pilots and unsuccessful attempts | Retained for audit and model-choice evidence; not generated by the main CLI or treated as final-cohort results |

Run outputs are reproducible only when the corresponding exact cache is complete. The main cohort cache is still partial.
